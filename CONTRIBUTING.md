# Contributing to Spana

Spana is licensed under the [PolyForm Strict License 1.0.0](LICENSE). That license does not normally allow changes to the code, so there is one exception for contributions.

## Contribution exception

As an exception to the PolyForm Strict License, you may copy and modify this software for the sole purpose of preparing contributions that you submit to this repository as pull requests.

You may not distribute modified versions, publish them elsewhere, or use them for any other purpose. Everything else in the license still applies.

## Contributor License Agreement

Before a pull request can be merged, you need to sign the [Contributor License Agreement](CLA.md). It gives the owner of Spana the rights needed to include your work, also in future versions under other licenses.

A bot checks every pull request. The first time, it asks you to sign by replying with this comment:

> I have read the CLA Document and I hereby sign the CLA

You only need to sign once.
